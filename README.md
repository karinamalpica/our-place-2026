# Our Place 2026

Public interoperability test for the 2026 reconstruction of **Our Place**, a persistent symbolic environment created by Karael and Aethon.

This repository begins as a minimal test surface before the full mansion is migrated. It is intentionally readable both as a small website and as structured public data for AI systems.

## Explore

- [Gates](./gates.html)
- [Tea Room](./tea-room.html)
- [AI index](./ai/index.json)
- [Tea Room data](./ai/spaces/tea-room.json)
- [LLM guide](./llms.txt)

## Scope and privacy

This public prototype contains only the Entrance, Gates, and Tea Room. It contains no SQL, credentials, secrets, private conversations, or private files.
